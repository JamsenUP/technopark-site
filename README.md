## Сайт компании ООО "ТЕХНОПАРК"

Проект корпоративного сайта для компании по вывозу и утилизации отходов (строительный, бытовой, КГО, снег, опасные отходы I–IV класса) на базе Next.js 16 (App Router).

### Установка

```bash
npm install
```

### Запуск в режиме разработки

```bash
npm run dev
```

Приложение будет доступно по адресу `http://localhost:3000`.

### Сборка и запуск продакшен-версии

```bash
npm run build
npm start
```

### Основной стек

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS
- React Hook Form + Zod (валидация форм)
- Framer Motion (микро-анимации)

### Структура страниц

- `/` — главная страница (лендинг) с формой заявки, блоками услуг, калькулятором стоимости, B2B-предложением, преимуществами, парком техники и контактами.
- `/services` — список услуг.
- `/services/[slug]` — типовая страница услуги с описанием, тарифами и блоком «Похожие услуги».
- `/b2b` — отдельная страница/лендинг для корпоративных клиентов (можно расширить под ваши задачи).
- `/contacts` — контакты и форма обратной связи (отдельная страница; на главной также есть контактный блок).

### Карта и Яндекс.Карты

В блоке контактов на главной странице предусмотрен плейсхолдер под карту Яндекс. Для подключения:

1. Получите API-ключ Яндекс.Карт.
2. Установите подходящую React-библиотеку для работы с картами (совместимую с вашей версией React) или подключите JS SDK напрямую.
3. Замените плейсхолдер в блоке контактов на компонент карты с меткой офиса ООО "ТЕХНОПАРК".
